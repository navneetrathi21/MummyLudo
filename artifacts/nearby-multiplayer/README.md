# Nearby multiplayer review assets

These files support the nearby multiplayer design and first implementation slice.

- `approved-board.png`: crop of the approved board used as the visual reference.
- `01-play-nearby.png`: emulator capture of the nearby play entry screen.
- `02-host-lobby.png`: emulator capture of the host lobby with a real generated game QR.

The emulator used software rendering because of host memory pressure and repeatedly displayed an Android System UI ANR dialog. Captures containing that operating-system dialog are not design references.
